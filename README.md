# AI 副驾 · Co-Pilot Life

**一句话简介**：你扮演重度依赖 AI 的开发者，逐任务决定「怎么用 AI」（提示词 / 评审 / 测试 / 重构），看现实软件工程规律如何在后期反噬——一个零依赖、双击即玩的网页经营模拟小品。

**双目标**
1. **训练软件开发的直觉与品味**：在「玩」中熟记真实工程规律（跳过评审→缺陷流入线上、技术债累积→改动成本指数上升）。
2. **趣味展示 AI agent 辅助开发**：用拟人化 agent trait 与随机事件，把「人机协作」过程做出梗、做出乐子。

**主题层（对人类未来的思考）**：当 AI 接管了「写」代码，人类还剩下「判断什么值得写、以及如何为后果负责」。游戏用「时代观察」文案与多结局点题——你不用会写每一行，但必须会判每一行。

> 游戏名为三个候选名（AI 副驾 / 提示词工厂 / 代码债）之一，当前代码用「AI 副驾」，最终名待人类负责人拍板。

## 怎么运行

**方式一：双击（零依赖、零构建）**
直接双击 `game/index.html`，浏览器即开即玩。无任何框架 / 库 / 构建 / npm / fetch / ES modules，纯 `<script src>` 顺序加载。

**方式二：命令行起本地服务器**
适合想从手机或局域网访问、或顺手用浏览器开发者工具调试时：

```bash
# 在仓库根目录（aigame/）执行
python -m http.server 8000
# 浏览器打开：
# http://localhost:8000/game/
```

> 提示：若系统里 `python` 指向 Python 2，改用 `python3 -m http.server 8000`。起好后按 `Ctrl+C` 停止。

## 怎么玩

### 一局流程（核心循环）
1. **接项目**：系统按本局 seed 抽一张项目卡（规模 / 甲方 / 隐藏需求 / 报酬 / 容忍工期与缺陷）。
2. **拆任务**：按规模自动拆成 N 个任务（S=3、M=5、L=8），每个任务配一个 AI agent。
3. **四维决策**：对每个任务，分别拨 4 个开关（提示词 / 评审 / 测试 / 重构）。
4. **执行**：掷出 agent 的拟人 trait 与随机事件，逐任务算出数值增量。
5. **结算**：汇总 7 项数值，给出评级（优 / 合格 / 失败）与成败判定。
6. **归因**：逐任务列出「所选策略 + 触发 trait/事件 + 对数值的增量」，正向绿、负向红，一眼看出「哪个决策导致什么结果」。
7. **时代观察**：按你的决策风格给一句点题文案。
8. **成长**：经验累积、技术债跨局带入、AI 版本随局数递增、解锁轻量修正。
9. **下一局**：保留 player 状态（经验 / 技术债 / 解锁），换新 seed 继续。

### 四维决策（每个任务独立）
| 维度 | 选项 | 直觉 |
|---|---|---|
| 提示词 | 省 / 精致 | 省=快但易误解；精致=慢、费 token、缺陷少、口碑+ |
| 代码评审 | 关 / 开 | 关=快但缺陷流入线上；开=慢、精力-、缺陷与债双降 |
| 写测试 | 关 / 开 | 关=快但回归缺陷难捕；开=慢、精力--、缺陷与债双降 |
| 重构 | 关 / 开 | 关=快但代码腐化债增；开=慢、精力-、技术债大降 |

**核心张力**：省 / 关 = 短期快，但技术债会在后续任务按系数放大工期与缺陷（放大被钳制在 0.6~1.5 倍，防雪崩）。精致 / 开 = 稳但慢、费精力；精力<0 触疲劳，缺陷再上浮。

### 7 项数值含义（结算面板）
| 数值 | 含义 | 备注 |
|---|---|---|
| 工期 | 交付耗时（周） | 最低 0.5 周；超时判定失败 |
| 缺陷 | 交付缺陷数 | 非负；超容忍阈值判定失败 |
| 技术债 | 本局新增债 | 可负（净偿还）；**跨局累积，是核心反噬源** |
| 口碑 | 客户评价 | 跨局累计、钳制 0~100；影响报酬 |
| 精力 | 本局剩余行动力 | 基线 10；<0 触发疲劳缺陷 |
| 资金 | 利润（万） | 报酬 − 基础成本 + 增量；<0 判定失败 |
| 经验 | 成长货币 | 成功 / 零缺陷 / 盈利 / 高质量给加成；欠债不涨经验 |

### 多结局是什么
按累计历史（风格 / 平均质量比 / 平均技术债）判定，结算后展示一条点题文案：
- **🤝 人机协作大师**：长期稳且优（均债≤6、均质≥0.6）。
- **💥 技术债崩盘**：长期重速度且债失控（均债>12、重速度局≥60%）。
- **🏭 流水线工人**：快但没崩（重速度局≥60%、均债≤8）——活干了，判断力没长。
- **🌱 觉醒的工匠**：长期偏平衡（平衡局≥50%）——吃过亏后开始重新掂量。
- **🐣 初出茅庐**：仅玩过 <2 局时的默认结局。

## 人类如何修改

**先记住分层纪律（很重要）**：
- `data.js` 只放「写死的常量与文案」，不写逻辑。
- `logic.js` 只算数，**绝不引用 `document` / `window` / `localStorage`**，可被 node 直接 `require` 单测。
- `ui.js` 只渲染，不直接算数值。
- `main.js` 只编排，不写复杂计算。
改数值时**只动 `data.js` 与 `logic.js`**，界面与流程会自动跟随，不用碰 DOM。

### 在 data.js 加内容 / 调数值
文件里每一项都标了 `// 待试玩校准`，对照改即可：

- **加项目卡 / 调规模**：`PROJECT_POOL`（约 55 行，数组，每项 `scale` 取 S/M/L）。
  规模对应的任务数、预算、缺陷容忍在 `SCALE_CFG`（约 69 行，S/M/L 三档）。
- **加 agent trait**：`TRAIT_POOL`（约 84 行，7 个，每项含 `name/desc/effect` 六维增量）。
- **加随机事件**：`EVENT_POOL`（约 97 行，12 个，每项含 `effect` 增量、`weight/chance`、`conditional` 条件事件标记）。
- **调事件发生概率**：`EVENT_CHANCE`（约 113 行，当前 0.45，单任务掷骰命中才触发）。
- **调四维数值表**：`STRATEGY_TABLE`（约 18 行，四维度 × 选项 × 六维增量，是平衡的核心旋钮）。
- **调成长解锁**：`UNLOCKS`（约 149 行，含 `needExp` 阈值与解锁描述）。
- **调文案**：`NARRATIVE`（时代观察，约 116 行）、`ENDINGS`（多结局，约 124 行）。

### 在 logic.js 调规则
若想改规则而非数值，集中在带注释处：
- 技术债放大钳制：`applyStrategy` 内的 `Math.max(0.6, Math.min(1.5, ampl))`（约 163 行）。
- 质量比口径：`computeQualityRatio`（约 332 行）。
- 经验公式：`computeExperience`（约 338 行）。
- 结局阈值：`pickEnding`（约 396~400 行，五条判定顺序）。
- 跨局推进：`advancePlayer`（约 416 行，AI 版本递增间隔 `AI_VERSION_INTERVAL` 取自 data.js）。

> 改完刷新页面即可见效；若数值怪异，优先回看 data.js 里那堆 `// 待试玩校准` 初值。

## 如何用 node 跑逻辑测试

`logic.js` 是 UMD 包裹：浏览器挂 `window.Logic`，node 下 `module.exports`。QA 已交付回归脚本 `tests/run-tests.js`（41 条断言，覆盖核心循环/同 seed 复现/条件事件/钳制/疲劳/成败/多结局/跨局成长/边界）：

```bash
# 在 aigame/ 下直接运行（无需安装任何依赖）
node tests/run-tests.js
```

> 注意：直接 `require('./game/js/logic.js')` 时 `GAME_DATA` 不会自动加载（logic.js 有空表兜底），正式测试需在同一个 vm 上下文按 `data.js → logic.js` 顺序加载——`tests/run-tests.js` 已示范该做法。

因为 logic 层所有随机都来自 `makeRng(seed)`，**同一个 seed 必产出同一局**——这也正是「决策→后果可复现、可归因」的工程基础。改动数值或规则后，跑一遍 `node tests/run-tests.js` 即可回归。

## 已知限制（设计文档明确砍掉 / 延后项）
- **无存档**：`file://` 下 `localStorage` 受限，当前用内存态，刷新即重开。
- **无 i18n**：仅中文，Steam 版再补多语言。
- **无音效 / 美术资源**：纯 emoji + CSS。
- **单人单局内存态**：无联机 / 排行榜，无成就系统。
- **无真实 AI 接口**：用确定性随机模拟「AI 行为」，不引入 fetch（保持零依赖）。

1. **人类试玩校准数值**：重点调 `data.js` 里标 `待试玩校准` 的初值（STRATEGY_TABLE / SCALE_CFG / EVENT_CHANCE / AMPLIFY 等），用固定 seed 快速回归。

3. **Steam 化**：用 Electron 套壳，或整体移植；`logic.js` 的纯函数分层已为「抽离核心玩法到原生/移植端」留好路，UI 层可替换而不动规则。

## 风险汇总
| 风险 | 现状 / 缓解 |
|---|---|
| file:// 下 localStorage 不可用 | 已砍存档，MVP 用内存态；存档延后 |
| 纯函数单测如何跑 | logic.js UMD 兼容 node `require`，无需构建（见上） |
| 数值平衡需大量试玩 | 用 seed 复现固定局快速回归，避免每次随机 |
| 「可归因」难 | 强制记录每步 seed 与增量，结算展示 attribution 面板 |
| 随机性冲淡严肃内核 | trait 夸张度与文案定调「幽默但不过界」，待人类确认 |
| 游戏名待定 | 三候选名之一，最终名待人类负责人拍板 |
