# 玩法设计说明 · AI 副驾

> 给玩家的「这游戏到底在玩啥」说明书。不教做人，只说乐子。

## 核心张力：省事一时爽，还债火葬场

你面前每个任务都有四个开关：**提示词（省/精致）、评审（关/开）、测试（关/开）、重构（关/开）**。

规律很直白——**全拨「省 / 关」**，这局交付快得像开了倍速；但技术债会像滚雪球，在后面任务里把工期和缺陷一起放大（系统很体贴地锁了 0.6~1.5 倍，免得你第一局就雪崩）。

所以真正的爽点不是「全选快」，而是**在快与稳之间反复横跳**——哪刀该省、哪刀不能省，全看你这名「AI 副驾」的品味。

## 几个「决策 → 反馈」的名场面

**场景一：跳过评审**
你心想「这点小改动 AI 不会翻车吧」，评审一关。结果 agent 是个「幻觉天才」，写得飞快但顺手编了个不存在的接口。缺陷 +2 直接流进线上，结算口碑 −，归因面板用红字把「评审关 + 幻觉天才」钉在耻辱柱上。下次你还敢不评审吗？（也许还敢，但心里有数了。）

**场景二：从不写测试**
工期一路绿，你飘飘然。直到某次改个小需求，旧逻辑被牵一发而动全身，回归缺陷全冒出来。设计文档原话：「不写测试 → 回归缺陷无法被早期捕获」。游戏把这翻译成：你省下的每一个测试，都标好了迟早要还的价。

**场景三：一路省到底**
短期资金报表好看，你成了「流水线工人」——活儿没少干，判断力却没长。等 AI 版本升了几级、旧提示词收益衰减，你才发现一直在按「生成」按钮，脑袋早交出去了。

## agent 的拟人 trait：你的「同事」都很戏精

每个任务配一个 AI agent，抽中谁全看脸：
- **过度设计癖**：爱加没用的抽象层，维护时你会想骂它。
- **幻觉天才**：写得快但常编出错，刺激。
- **捷径大师**：怎么快怎么来，技术债 +。
- **严谨老学究**：慢但极少出错，稳如老狗。
- **马屁精**：顺着你、不敢质疑需求，口碑虚高隐患埋雷。
- **偷懒鬼**：能不写就不写，缺陷 +。
- **完美主义**：慢、爱重构，债 −。
- **健忘助手**：长任务易丢需求，交付偏离、口碑 −。
- **抠门精算师**：为省 token 砍注释与日志，债 +、但短期省力。
- **冒进新人**：敢用没把握的新技术，尝鲜的代价是工期与债双 +。

乐趣就在「同一个你，配不同戏精 agent，结果天差地别」——像在带一支性格迥异的远程团队。

## 随机事件：甲方永远不让人失望

18 种事件随时砸脸：**甲方周五晚改需求**（工期 +1 周）、**模型大版本更新**（旧提示词返工↑）、**服务器宕机**、**灵感爆发**（一次过）、**开源库爆漏洞**、**同事离职**（精力−）、**投资人加预算**、**竞品抢先发布**……还有第二批：**需求评审被推翻**、**CI 排队地狱**、**依赖地狱**、**客户试用好评**、**法规突变**、**技术浪潮冲击**。

部分是条件型：比如「新语言/框架流行」——你写了测试就顺手，没写就踩坑返工；「竞品抢先发布 / 技术浪潮」——你技术债低就缓冲冲击，债高就被重创。所以事件不是纯运气，你的前期决策会决定它到底是惊喜还是惊吓。

## 时代观察 & 多结局：点题不点穴

每局结算，系统先按你的风格给你一句「时代观察」（重速度 / 重质量 / 重平衡）。除此之外，还会按你的**进程**叠加一条情境观察，把"AI 接管写代码，人类还剩什么"越点越透：
- **📉 重负债**：跨局累计技术债过高时——「AI 帮你写的每一行快代码，迟早要在某个深夜连本带利还。」
- **🤖 重替代**：AI 版本升到 v3+ 时——「这一版 AI 又能自动做一件你曾引以为傲的事……手里还剩什么筹码？」
- **🤝 重默契**：连续 3 局以上稳稳交付时——「它写得快，你判得准，这或许就是新时代最值钱的搭档关系。」

玩够了（≥2 局）还会按累计历史给一个结局：**人机协作大师 / 技术债崩盘 / 流水线工人 / 觉醒的工匠 / 涅槃重生 / 数字流水线幽灵 / 初出茅庐**。

它们不是「赢家输家」的审判，而是一个温柔的提醒——**当机器接管「写」，人类最贵的能力是「判」**。你不必会写每一行，但得会判每一行。这，就是这款小游戏想让你在笑完之后，心里留着的那点东西。
